# Modified KanjiVG SVG Graphics

This repository contains modified SVG graphics derived from the [KanjiVG](https://github.com/KanjiVG/kanjivg) project and used in the InteractiveLearningApplication Android application.

## Modifications

The original KanjiVG SVG files have been modified for use in the InteractiveLearningApplication Android application.

The modifications include removing unnecessary stroke data and adapting the SVG files for the application's stroke-order animation functionality.
